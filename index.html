A few common questions

Good to know.

Can a supernode read my conversations?

No. It sees routing metadata, room names, and file names, but cannot read your messages or file contents.

Do I have to run a supernode?

No. Use someone else’s if you prefer. One-to-one conversations can connect directly; rooms need a supernode.

Does it work when someone is offline?

Both sides must be online. Messages are not stored on a server for later delivery.

Was AI used in development?

Yes. Tools including Claude, Cursor, Codex, and Grok have been used during development.
