Build 68 · Android release notes

Prefer a portable Windows nightly?

Download the unsigned Windows portable nightly, extract the whole archive with a 7z-compatible tool, then run DoubleSlash.exe from the extracted folder.

Updating an existing Android installation?

Install the APK over your existing app. If Android reports a signature mismatch, keep the existing installation: uninstalling removes its local identity and messages. See the Android release notes before proceeding.

Looking for checksums, supernodes, or source code?

The full releases page includes portable packages, SHA-256 checksums, supernode downloads, and source archives. These extra files are not required for a normal app installation.
